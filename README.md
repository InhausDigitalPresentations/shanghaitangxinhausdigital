# Shanghai Tang Abu Dhabi — Dressed for Dinner

Creative-direction treatment for the Shanghai Tang Restaurant Abu Dhabi opening film. Produced by Inhaus Digital.

It's a static site with no build step, so it's ready for GitHub Pages.

## Publish on GitHub Pages
1. Create a repository and upload everything in this folder: `index.html`, `.nojekyll`, `README.md` and the whole `img/` folder. Keep `img/` next to `index.html`.
2. Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, then **main / root**, and save.
3. After a minute or two the site is live at `https://<user>.github.io/<repo>/`.

## Presenting
- On desktop, scroll (or swipe sideways on a trackpad) to move through the story; the arrow keys jump one spread at a time.
- The menu at the top right and the Contents spread jump to each chapter.
- On phones it becomes a vertical story.
